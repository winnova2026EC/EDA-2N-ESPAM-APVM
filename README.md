## Descripción

Este proyecto contiene la implementación de estructuras de datos lineales utilizando Java.

## Tema del foro

**TDA Pila (Stack - LIFO)**

Aplicación de las funciones Deshacer (Undo) y Rehacer (Redo) en un editor de texto, utilizando dos pilas para guardar y recuperar modificaciones.

## Estructuras implementadas

- Arreglos y matrices.
- Listas enlazadas.
- Pilas LIFO.
- Colas circulares FIFO.

## Tecnologías

- Java
- Visual Studio Code
- GitHub

## Ejecución

Abrir el archivo `Main.java` en Visual Studio Code y ejecutar con Run Java.
